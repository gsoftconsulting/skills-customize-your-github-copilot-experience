# 📘 Assignment: Statistics with Python

## 🎯 Objective

Students will use pandas and numpy to load a dataset, inspect its structure, and calculate common statistical measures. Skills used: data loading, data inspection, descriptive statistics, aggregation, numpy calculations, and basic data analysis.

## 📝 Tasks

### 🛠️ Load and Inspect the Dataset

#### Description
Open the provided CSV file with pandas and inspect the data to understand its columns, rows, and numeric fields.

#### Requirements
Completed program should:

- Load the provided CSV file using pandas
- Display the first 5 rows of the dataset
- Show the data types and a summary of the dataset structure


### 🛠️ Calculate Descriptive Statistics

#### Description
Use pandas and numpy to calculate key statistics for the numeric columns in the dataset.

#### Requirements
Completed program should:

- Calculate the mean, median, and standard deviation for at least two numeric columns
- Find the minimum and maximum values for the same columns
- Use numpy to calculate at least one additional statistic, such as variance or percentile


### 🛠️ Summarize Findings

#### Description
Write a short summary of what the statistics reveal about the dataset.

#### Requirements
Completed program should:

- Identify at least two interesting observations from the calculated statistics
- Use clear, student-friendly language in the summary
- Print the summary to the console or save it to a text file
